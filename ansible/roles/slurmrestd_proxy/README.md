# slurmrestd_proxy

This role configures apache as a reverse proxy and TLS endpoint for slurmrestd
running on the same host.

It makes the Slurm REST API available on port 443.

See the slurmrestd deployment by the [ansible-role-openhpc](https://github.com/stackhpc/ansible-role-openhpc) role.

## Usage

Please see [docs/slurmrestd.md](../../docs/slurmrestd.md) for general setup.

Following are the details about defining custom SSL Certificates and Let's Encrypt integration.

## SSL Certificates

This role enables TLS on the reverse proxy, using the following self-signed certificate & key which are autogenerated by the `mod_ssl` package installed as part of the `ondemand-apache` package. Replace with your own keys if required.

- `slurmrestd_proxy_ssl_cert`: Optional. Default `/etc/pki/tls/certs/localhost.crt`.
- `slurmrestd_proxy_ssl_cert_key`: Optional. Default `/etc/pki/tls/private/localhost.key`

Alternatively, you can generate a certificate from Let's Encrypt automatically by configuring the following variables:

- `slurmrestd_proxy_certbot`: Optional. Default is false. Set to true to request a certificate from Let's Encrypt.
- `slurmrestd_proxy_certbot_email`: Required when `slurmrestd_proxy_certbot` is true. Email address for registration and recovery contact. Can provide multiple comma-separated addresses.
- `slurmrestd_proxy_certbot_staging:` Optional. Whether to use Let's Encrypt staging server to provide (invalid) test certs. For testing and development only.

If using Let's Encrypt:

- Leave `slurmrestd_proxy_ssl_cert` and `slurmrestd_proxy_ssl_cert_key` set to their default values.
- `slurmrestd_proxy_servername` must be a valid DNS name, not an IP.
- Port 80 on the `slurmrestd` host must be externally accessible.
- Certificates will be renewed automatically by the systemd timer `certbot-renew.timer`.

## Other variables

- `slurmrestd_proxy_port_80_redirect_enabled`: Optional. Default `true`. Set to `false` to disable listen on port 80 and redirecting to the TLS port
- `slurmrestd_proxy_servername`: Optional. Default `ansible_host` (i.e. IP address) of `slurmrestd` host. `ServerName` for the slurmrestd_proxy apache config. Needs to be different to `openondemand_servername` or use a different port via `slurmrestd_proxy_tls_port`.
- `slurmrestd_proxy_ssl_options`: Optional. Default is the options as openondemand. List of apache configuration options like `SSLProtocol`, etc.
- `slurmrestd_proxy_tls_port`: Optional. Default `443`. Main port for slurmrestd_proxy, where it will forward requests to slurmrestd.
